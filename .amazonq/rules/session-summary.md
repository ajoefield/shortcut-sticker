# Session Summary Rule

When the user types `/end-session` or `/summarize-session`, automatically:

1. **Analyze the current chat history** for:
   - Features implemented
   - Problems solved
   - Technical decisions made
   - Ideas discussed
   - Bugs discovered

2. **Update documentation files** in the `docs/` folder:
   - Add timestamped entries to `development-log.md`
   - Add new ideas to `feature-ideas.md` 
   - Add narrative moments to `story-timeline.md`

3. **Use proper formatting**:
   - Current date: 2025-12-09
   - User timezone: MT (Mountain Time)
   - Timestamp format: [HH:MM MT]

4. **Extract key information**:
   - Code changes made
   - UI/UX improvements
   - Database modifications
   - New features added
   - Technical challenges overcome

5. **Organize by priority**:
   - Completed work → development-log.md
   - Future ideas → feature-ideas.md
   - Story moments → story-timeline.md

This rule ensures consistent documentation of development progress for future blog content and project tracking.
